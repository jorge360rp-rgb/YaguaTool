# Validación 3.1.3

`FINISH.json` comprueba las superficies con gradiente y relieve, los estados activos, el halo, las previews de Movimiento azules, la ausencia del reproductor de Complex, los nombres y el foco de ratón/teclado. Incluye capturas de cada grupo revisado.

`RESULTADOS.json`: 60 estados de interfaz nativa, 33 presets del Lab, 76 resultados de búsqueda, sintaxis JavaScript y 25 archivos de motor/host/recursos preservados por SHA-256. `RESPONSIVE450.json`: 450 combinaciones de la propuesta visual sin errores de geometría. `ACCESIBILIDAD.json`: cero infracciones axe en las pantallas revisadas.

`CHROMIUM99.json` analiza el CSS para Chrome 99, con advertencias de máscaras junto a la implementación WebKit. La ejecución real usa el Chromium instalado, no CEF99. La instalación Windows/macOS y el render dentro de AE siguen pendientes de prueba en After Effects.
